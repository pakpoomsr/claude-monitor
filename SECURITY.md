# Security Policy

## Supported versions

Only the latest release of Claude Monitor receives security updates.

## Reporting a vulnerability

Please report security issues privately. Do **not** open a public GitHub issue.

- Open a [private security advisory](https://github.com/pakpoomsr/claude-monitor/security/advisories/new) on GitHub,

Include reproduction steps, affected version, and your assessment of impact. We aim to acknowledge reports within 72 hours.
